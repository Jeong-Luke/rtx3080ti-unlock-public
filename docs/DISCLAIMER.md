# 무보증·사용자 책임·책임 제한

**이 공개본은 실험용이며, 명시적·묵시적 보증 없이 현재 상태 그대로(“AS IS”) 제공됩니다. 사용 및 사용 불능으로 인한 위험은 사용자에게 있습니다. 관련 법률이 허용하는 최대 범위에서, 별도의 서면 약정이 없는 한 작성자·저작권자·관리자·기여자·수정자·재배포자는 그로 인한 손해에 책임을 지지 않습니다.**

## 1. 보증하지 않는 사항

소스, 스크립트, 문서, 예시, 측정 자료 및 이를 바탕으로 사용자가 만든 산출물에 대해 정확성, 완전성, 상품성, 특정 목적 적합성, 장비 호환성, 안전한 실행, 성능 향상, 정상 부팅, 복구 가능성 또는 지속적인 유지보수·지원을 보증하지 않습니다.

한 장비의 성공 기록, 단위 테스트 통과, 파일 해시 일치, 에이전트의 검토·안내 또는 사용자의 실행 승인은 다른 장비나 향후 실행의 성공·안전성을 보증하지 않습니다. 자동화 도구나 다른 사람의 안내를 거쳐 실행하더라도 이 위험이 없어지지 않습니다.

## 2. 사용자 판단과 비용

사용자는 자신의 장비·환경·보안 정책·라이선스를 확인하고, 필요한 백업과 복구 수단을 마련한 뒤 사용 여부를 판단해야 합니다. 보증이 없다는 설명은 위험한 실행을 승인하거나 안전 절차를 생략하라는 의미가 아닙니다.

가능한 문제에는 GPU·주변 장치의 오동작이나 손상, 화면 소실, 부팅 실패, 데이터 손실·훼손·부정확성, 보안 문제, 프로그램 간 충돌, 서비스 중단, 작업·수익 손실, 제3자에게 발생하는 손해가 포함됩니다. 이 목록은 모든 위험을 열거한 것이 아닙니다.

관련 법률 또는 별도 서면 약정이 달리 정하지 않는 범위에서, 사용자는 필요한 점검·수리·복구·수정 비용을 부담합니다. 저장소 운영자는 무상 수리, 데이터 복구, 손실 보상 또는 개별 지원을 약속하지 않습니다.

## 3. 책임 제한과 적용 한계

관련 법률이 허용하는 최대 범위에서, 별도 서면 약정이 없는 한 작성자·저작권자·관리자·기여자·수정자·재배포자는 사용 또는 사용 불능으로 발생하는 일반적·특별·부수적·결과적 손해에 책임을 지지 않습니다. 그러한 손해의 가능성을 미리 통지받은 경우도 포함합니다.

**다만 관련 법률에 따라 배제하거나 제한할 수 없는 책임·권리에는 이 제한이 적용되지 않습니다.** 이 문서는 모든 관할이나 모든 사정에서 법적 책임이 완전히 사라진다는 보장이 아닙니다. 실제 적용 범위는 관련 법률과 구체적인 사실관계에 따릅니다.
